# Cuiaba Fb Tabacaria

Crie uma loja virtual responsiva (computador e celular, mobile-first) para a "FB Tabacaria", de Cuiabá-MT, com visual elegante, escuro e moderno. Todo o conteúdo em português do Brasil.

IDENTIDADE VISUAL

- Fundo azul-marinho muito escuro / quase preto (#050B1A a #0A1A3A), com gradientes sutis.

- Cor de destaque: azul elétrico neon (#1E6BFF / #2F8CFF), com brilho (glow) em botões, bordas e títulos.

- Texto principal
